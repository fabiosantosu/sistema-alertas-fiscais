# Sistema de Alertas Fiscais

MVP (Minimum Viable Product) desenvolvido como requisito prático para a disciplina de Projeto de Software. O sistema auxilia microempresas no gerenciamento e cálculo de prazos de compensações financeiras e obrigações fiscais.

## 🛠️ Tecnologias Utilizadas
* **Back-end:** Python (Flask)
* **Front-end:** HTML5, CSS3 (Bootstrap 5.3)
* **Banco de Dados:** PostgreSQL
